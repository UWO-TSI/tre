# TRE Website - Content Management Guide

Welcome! This guide will help you manage events and help guides for the TRE website using Sanity CMS.

## Accessing the CMS

### 1. Navigate to the Admin Panel

Open your web browser and go to:

```
https://your-website-url.com/sanity
```

_(For local development: `http://localhost:3000/sanity`)_

### 2. Sign In

You'll see a login screen with three options:

- **Google** - Sign in with your Google account
- **GitHub** - Sign in with your GitHub account
- **Email/Password** - Sign in with email and password

Choose your preferred method and complete the authentication.

## Managing Events

### Adding a New Event

1. **Navigate to Events**
   - After logging in, click on **"Manage Events"** in the left sidebar

2. **Create New Event**
   - Click the **"+ Create"** button or **"New Event"** button
   - You'll see a form with the following fields:

3. **Fill in Event Details**

   | Field              | Description                                       | Required |
   | ------------------ | ------------------------------------------------- | -------- |
   | **Event Title**    | The name of your event                            | ✅ Yes   |
   | **Event Date**     | Date and time when the event occurs               | No       |
   | **Location**       | Where the event takes place                       | No       |
   | **Description**    | Detailed information about the event              | No       |
   | **Featured Event** | Toggle ON to highlight this event on the homepage | No       |

4. **Save Your Event**
   - Click **"Publish"** to make the event live on the website
   - Or click **"Save as Draft"** to save without publishing

### Editing an Existing Event

1. Click **"Manage Events"** in the sidebar
2. Find the event you want to edit in the list
3. Click on the event to open it
4. Make your changes
5. Click **"Publish"** to save changes

### Deleting an Event

1. Open the event you want to delete
2. Click the **three dots menu** (⋮) in the top right
3. Select **"Delete"**
4. Confirm the deletion

## Managing Help Guides

Help guides are instructions for managing different aspects of the website. These are useful for training new team members or documenting processes.

### Creating a New Guide

1. **Navigate to Guides**
   - Click on **"Help & Guides"** in the left sidebar

2. **Create New Guide**
   - Click the **"+ Create"** button

3. **Fill in Guide Details**

   | Field            | Description                                          | Required |
   | ---------------- | ---------------------------------------------------- | -------- |
   | **Guide Title**  | Name of the guide (e.g., "How to Add Events")        | ✅ Yes   |
   | **Category**     | Choose from: Events, Images, or General              | No       |
   | **Instructions** | Step-by-step instructions using the rich text editor | No       |

4. **Using the Rich Text Editor**

   The Instructions field supports rich formatting:
   - **Bold** and _italic_ text
   - Bullet points and numbered lists
   - Headings for organization
   - Links to other resources

   To format text:
   - Highlight the text you want to format
   - Use the formatting toolbar that appears
   - Or use keyboard shortcuts (Ctrl/Cmd + B for bold, etc.)

5. **Save Your Guide**
   - Click **"Publish"** to make it available
   - Or **"Save as Draft"** to continue editing later

### Organizing Guides by Category

Use the **Category** field to organize your guides:

- **Events** - Guides about managing events
- **Images** - Guides about uploading and managing images
- **General** - Other website management guides

## Tips for Success

### ✅ Best Practices

1. **Event Titles**
   - Keep them clear and descriptive
   - Example: "Annual Fundraising Gala 2026" instead of just "Gala"

2. **Event Dates**
   - Always include the date and time for upcoming events
   - This helps visitors plan to attend

3. **Featured Events**
   - Only feature 1-3 events at a time
   - Feature your most important upcoming events

4. **Guide Writing**
   - Write step-by-step instructions
   - Use numbered lists for sequential steps
   - Include screenshots when helpful

### 💡 Helpful Features

- **Drafts**: Save work in progress without publishing
- **Preview**: See how content will look before publishing
- **Version History**: Revert to previous versions if needed
- **Search**: Use the search bar to quickly find content

## Important Notes

> [!IMPORTANT]
> **Publishing vs. Drafts**
>
> - **Publish**: Makes content immediately visible on the live website
> - **Draft**: Saves your work but doesn't show it publicly

> [!WARNING]
> **Deleting Content**
>
> - Deleted content cannot be easily recovered
> - Always double-check before confirming a deletion

> [!TIP]
> **Save Frequently**
>
> - Click "Save as Draft" regularly while working
> - This prevents losing your work if something goes wrong

## Troubleshooting

### Can't see my published event on the website?

- Make sure you clicked "Publish" (not just "Save as Draft")
- Wait a few minutes for the website to update
- Try refreshing your browser

### Lost my changes?

- Check the **"Drafts"** section in the sidebar
- Your work may have been auto-saved

### Can't log in?

- Make sure you're using the correct login method
- Contact your administrator to verify your account access
